# 枕头快跑 · Forest Dash

打开即玩的森林跑酷小游戏，使用自定义人物贴图。单个 HTML 文件包含所有图片、样式和代码，无需构建或安装依赖。

游玩地址：https://shit466.github.io/forest-dash/

## 操作

- 电脑：左右方向键换道，上方向键 / 空格跳跃，下方向键滑行，P / Esc 暂停。
- 手机：滑动屏幕，或使用底部按钮。
- 树桩跳过、藤架滑过、岩石换道躲避。
- 护盾抵挡一次碰撞；磁铁自动收集附近绿头巾。
- 得分为奔跑距离加绿头巾数乘以 15；最高分保存在当前浏览器。

## 本地运行

直接用浏览器打开 `index.html`。也可运行 `python3 -m http.server 8000` 后访问 `http://localhost:8000`。

## 发布

GitHub Pages 从 `main` 分支根目录发布。更新 `index.html` 并提交即可更新游戏。
